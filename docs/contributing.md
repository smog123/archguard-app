# Contributing

Contributions to Archguard's contracts, applications, and documentation are welcome.

For guidelines on repository structure, code standards, testing practices, and submission workflows, refer directly to each repository's contribution guide:

- **Contracts Repository (`archguard-contract`)**: [CONTRIBUTING.md](https://github.com/smog123/archguard-contract/blob/main/CONTRIBUTING.md)
- **Applications Repository (`archguard-app`)**: [CONTRIBUTING.md](https://github.com/smog123/archguard-app/blob/main/CONTRIBUTING.md)

## Security Vulnerabilities

Please report any suspected security issues or vulnerabilities according to the instructions in [SECURITY.md](https://github.com/smog123/archguard-app/blob/main/SECURITY.md).
