# Contributing to Archguard

## Setup

Follow the quick-start steps in the [README](README.md) — install Node 20+,
`npm install`, and confirm the SDK builds — to get a working setup before
making changes.

## Making changes

1. Fork the repo, create a branch off `main`
2. Make your change with tests (`npm test -w packages/sdk`, `npm test -w indexer`)
3. Open a PR — CI must pass before merge
4. One approval required

## Commit style

Conventional commits: `type(scope): description`
